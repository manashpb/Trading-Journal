I want to create a trading journal for prop firm trades in Futures or CFD. There will be a main page, giving the summary of performance, detailed breakdown of statistics, day wise pnl calendar and other appropriate graphical plots. This page should be designed in such a way that later on, new analyis can be added, without disturbing the other pages. 

The second page - Trade log page - will have two parts - Add a new trade and view trade log. When add a new trade is clicked, a popup window appears for providing the following information for a new trade:
Instrument, CFD or Futures, Date and time of entry, Long or Short, Entry price, SL price, Target price, Qty, Date and time of Exit, Exit price, Status, PnL, Tags, Comments, Snapshots. Not all the information has to be mandatorily provided, they can be added/edited later. Date and time columns should have date time picker, instrument, CFD or Futures and Long or Short should be select dropdown list. Prices should be numeric with two decimal, Status should be dropdown select with Open or Closed. PnL will be autocalculated for Closed trades. Tags will be a checkbox list for multiple selections, the list of tags will be created in a separate page, mentioned below. The snapshots can be provided in two ways - upload a picture or paste an image from clipboard directly. These images will be stored in a folder, suitably named with the trade data (like trade entry datetime, instrument etc.) so that they appear serially in the file browser and can be sequentially traversed. Note that multiple snapshots may be provided for a single trade, also they can be edited or deleted later.   

Below, there will a tabulated or card view (changable by user) record of the trades (card view will show the trade snapshot images in the preview). There will be option to open and edit an existing trade. Also, there should be a quick way to cycle back/front through the trades in the card mode through keyboard shortcuts left and right. Also, there should be option to filter the trades (based on date range, tags, status etc) and sort based on differnt columns. Also, the filtered data can be exported to CSV files. The timestamps should always be in IST. Also, the path of the snapshot images should be there in the exported CSV and the tags separated by semicolon. 

Then, there will be a separate page for configuration, here the user can add instruments and set the Instrument vs per point PNL value (used in PNL calculation), these instruments will be visible in the dropdown for instruments in the add new trade. Also, there will be options to create different tag categories and tags under these categories. These tags will be visible in the tags column in the trade log page.
