# Combined server migration guide moved

Cross-application server operations now belong to VCCL Workspace.
The original server-transfer guide and its user edits are preserved at
[the historical server migration record](../../workspace/docs/history/SERVER-MIGRATION-LEGACY.md).

For the extracted portal's current paths and lifecycle, use
[the workspace deployment guide](../../workspace/docs/DEPLOYMENT.md).
Future server transfers must include workspace code and its private .env in
addition to journal data/screenshots and FNO data/configuration.
